# Festival tent map

One web page for placing tent spots on the festival grounds and tracking their
status. Pick a tent size, tap the ortho, and a true-size square is placed and
saved. Tap a tent to change its status, renter, fee or notes, turn it, move it
or delete it.

The page reads and writes an ArcGIS Online layer through an API key pasted
into `index.html`. Anyone who has the page can edit the tents.
